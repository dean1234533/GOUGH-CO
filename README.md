# Solicitors' website concept (Gough & Co)

**A one-page website concept for an East London solicitors' firm, with legal services, client testimonials, and a contact section designed to drive free consultation bookings.**

## Features

- A hero section with a clear "book a free consultation" call to action
- A **legal services** overview for individuals and families
- **Client testimonials**
- A **contact section**
- A responsive layout with a light and dark section rhythm

## Tech stack

Hand-written HTML, CSS, and vanilla JavaScript. It has no frameworks and no
build step.

```
index.html
css/style.css
js/main.js
assets/
```

## Run locally

```bash
git clone https://github.com/dean1234533/GOUGH-CO.git
cd GOUGH-CO
open index.html
```
